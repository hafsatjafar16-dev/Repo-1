# EU Market Entry Checklist — Cosmetic Product

Working checklist for taking a client's cosmetic product from "formula ready"
to "legally placed on the EU market" under Regulation (EC) 1223/2009. Copy per
client/per SKU; strike through what doesn't apply.

## Phase 0 — Qualification
- [ ] Confirm the product is in scope as a *cosmetic* (not biocide / medical
      device / medicinal product) — Art. 2 borderline check. If it leans
      device (mechanism-based claim, not just cosmetic function), see
      `eu-1223-2009-overview.md` §12 before scoping as a standard cosmetics
      engagement — MDR conformity is a different, heavier engagement.
- [ ] Identify target market(s): EU27 only, or also UK/CH/other EMEA — this
      determines whether one RP+notification is enough or multiple are needed
- [ ] Confirm who will act as Responsible Person (client itself if EU-based, or
      RP-as-a-service)

## Phase 1 — Formula & substance screening
- [ ] Full formula screened against Annex II (prohibited)
- [ ] Restricted-use ingredients checked against Annex III conditions
      (concentration, area of use, warnings required)
- [ ] Colorants checked against Annex IV, preservatives against Annex V, UV
      filters against Annex VI
- [ ] CMR 1A/1B/2 substances screened (Art. 15) — exemption needed if present
- [ ] Nanomaterial content identified, if any (separate 6-month notification)
- [ ] Allergen content checked against current disclosure thresholds
      (0.001% leave-on / 0.01% rinse-off)

## Phase 2 — Safety
- [ ] CPSR Part A compiled (formula, physico-chemical data, micro quality,
      packaging compatibility, exposure, toxicological profile)
- [ ] Qualified Safety Assessor engaged for CPSR Part B sign-off
- [ ] GMP compliance confirmed/documented (ISO 22716 reference)
- [ ] Stability testing + PAO (or expiry date) determined

## Phase 3 — Claims
- [ ] All marketing claims checked against the 6 common criteria (Reg.
      655/2013): legal, truthful, evidenced, honest, fair, informs decisions
- [ ] Substantiation dossier assembled for higher-risk claims (efficacy,
      "free-from," naturalness, hypoallergenic, etc.)
- [ ] If UK is a target market: claims also checked against the CAP Code
      (ASA) — a separate bar from the EU six criteria, not automatically
      satisfied by EU compliance. See `uk-claims-asa-cap-code.md`.

## Phase 4 — Labelling
- [ ] RP name/address on label
- [ ] Nominal content
- [ ] Durability date or PAO symbol
- [ ] Precautions for use / restricted-substance warnings
- [ ] Batch code
- [ ] Product function stated (if not obvious)
- [ ] Full INCI ingredient list, correct order, colorants (CI numbers) last
- [ ] Country of origin (if imported)
- [ ] Translated into required language(s) for each Member State of sale

## Phase 5 — PIF assembly
- [ ] Product description
- [ ] CPSR (Parts A + B, signed)
- [ ] Manufacturing method / GMP statement
- [ ] Claims substantiation
- [ ] Animal testing data statement
- [ ] PIF stored at RP address, accessible on request, retained 10 years post
      last batch

## Phase 6 — Notification & launch
- [ ] CPNP notification submitted (per product/variant) before first sale
- [ ] If selling in UK: separate SCPN notification via OPSS + UK RP confirmed
- [ ] If selling in CH: separate Swiss notification + CH RP confirmed
- [ ] Launch date confirmed only after notification acknowledgement received

## Phase 7 — Post-market
- [ ] SUE monitoring/reporting process agreed with client (who reports what,
      to whom, within what timeframe)
- [ ] PIF update process agreed for formula/label changes
- [ ] Annex amendment monitoring in place (recurring compliance check, not
      one-off) — flag as a retainer service opportunity
